# Paste Gumroad URLs in 5 minutes

1. Publish 3 products on Gumroad (see PHONE_SELL.md)
2. Copy each product URL
3. In repo `index.html` replace:
   - `GUMROAD_PROMPTS_URL`
   - `GUMROAD_HOOKS_URL`
   - `GUMROAD_LANDING_URL`
4. Replace `254XXXXXXXXX` with your WhatsApp (no +)
5. Commit → https://m3lcharagu.github.io/kyla-store/ live
